# Libreyolo-examples

Google ColabのGPUによるLibreyoloを使用したRF-DETRおよびYOLOモデルの使用方法の例です。

　・学習前モデルによる推論（画像の中の人物検出）
 
　・モデルの学習（データセットのアノテーションは、弊社のAutoannotationで自動作成）
 
　・学習後モデルによる推論（画像の中の人物検出）
 
　・学習モデルにSAHIアルゴリズムを適用した例
 
 
尚、学習用データセットは、学習例が目的で、全ての人物検出を網羅しているデータセットではない。
